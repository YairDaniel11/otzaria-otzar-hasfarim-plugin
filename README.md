# אוצר הספרים (תוסף אוצריא)

מידע ביבליוגרפי על ספרים עבריים ומחבריהם: מהדורות, מקום ושנת הדפסה, מדפיס, סדרה, הסכמות, ובאילו בתי כנסת, ישיבות וספריות הספר נמצא.

## מה בתוסף

- חיפוש ספרים ומחברים, עם נרמול עברי (גרשיים, ה' הידיעה, כתיב מלא וחסר).
- כרטיס ספר: מחבר, מהדורות, מדפיס, סדרה, הסכמות והערות, ומיקומי הספר.
- כרטיס מחבר: שמות וכינויים, שנות חיים (כשידועות) וכל ספריו בקטלוג.
- לחיצה ימנית על טקסט מסומן בקורא פותחת את התוסף על התוצאה
  (`contributes.startup.contextMenuItems`, `openPlugin: true`).
- פתיחת הספר באוצריא, עם חלונית בחירה כשיש כמה מועמדים, ותצוגה מקדימה של תחילת הטקסט.

## מבנה הנתונים

הנתונים נטענים בשברים, לפי הצורך, מתוך `src/data/`:

- `cat-index.js` - האינדקס הראשי: מחברים, טבלאות התחלה של השברים ורשימת הספריות.
- `shards/cat-<ver>-b<n>.js` - רשומות ספרים. הגרסה בשם הקובץ (לא ב-`?v=`).
- `shards/cat-<ver>-a<n>.js` - רשומות מחברים.
- `shards/cat-<ver>-p<n>.js` - מחיצות אינדקס חיפוש ספרים, לפי תחילת הכותר.
- `src/js/catalog-data.js` - נרמול, חיפוש וטעינה עצלה (`window.CAT`).

## כללי איחוד

- וריאנטים של שם מחבר מתאחדים למחבר אחד (היפוך "משפחה, פרטי", הסרת תארים, ה' הידיעה, גרשיים, כתיב מלא וחסר).
  שנות חיים סותרות חוסמות איחוד, ושם פרטי זהה לבדו אינו מספיק.
- מהדורות של אותו ספר מקובצות תחת יצירה אחת; מהדורה נקבעת לפי שנה (±1) ומקום.
- הערות מהדורה שנכתבו בשדה המחבר ("מהד' ...", "הו' ...") נשמרות כהערת מהדורה ולא כמחבר.

## מגבלות ידועות

- האיחוד אוטומטי, וייתכנו בו טעויות. שמות נפוצים בלי אב או שנות חיים עלולים להתאחד לאדם אחד.
- חיפוש ספרים לפי מילה שאינה תחילת הכותר דורש "חיפוש מורחב".
- כתובות בתי הכנסת והספריות חלקיות, וחלקן לא אומתו.
